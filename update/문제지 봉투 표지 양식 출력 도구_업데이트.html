📂 문제지 봉투 출력 도구, 이렇게 바뀌었습니다

기존에 쓰시던 화면 그대로, 아래 3가지가 추가/개선됐습니다.

✂️ 절취선이 정확히 페이지 가운데로

인쇄했을 때 페이지마다 절취선(가운데 점선) 위치가 조금씩 달라지던 문제를 구조적으로 고쳤습니다.

이전: 페이지마다 위치가 미세하게 어긋남
이후: 모든 페이지 정확히 절반 지점 고정

🖨️ 프린터 여백 보정 기능 추가

일부 프린터는 1페이지와 2페이지 이후의 상단 여백이 다르게 인쇄되는데, 이걸 직접 보정할 수 있는 칸이 생겼습니다.

평소엔 제목만 보이고, 클릭하면 펼쳐져서 mm 단위로 조절할 수 있습니다. (우리 프린터 기준값은 이미 기본으로 입력해뒀습니다.)

🔍 과목명으로 기본정보 자동 입력

이제 화면 위쪽에 "✏️ 직접 입력" / "🔍 과목명으로 가져오기" 탭이 생겼습니다.

가져오기 탭에서 과목명을 몇 글자만 치면 학년도·학기·차수·학년·평가월·평가일·평가교시·과목명이 자동으로 채워집니다.

단, 출제 교사와 교실별 인원(세부 정보)은 이전과 똑같이 직접 입력하셔야 합니다.

자료가 없거나 원하는 과목이 검색되지 않으면, 언제든 "✏️ 직접 입력" 탭으로 이전처럼 사용하시면 됩니다.

사용 중 궁금한 점이나 이상한 부분이 있으면 편하게 말씀해주세요 🙂
