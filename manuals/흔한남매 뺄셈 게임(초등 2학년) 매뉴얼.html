흔한남매 뺄셈 게임(초등 2학년)

사용 매뉴얼

1. 개요

인기 캐릭터 "흔한남매"(으뜸이 & 에이미)를 내세워, 뺄셈 문제를 풀어 악당을 물리치는 초등 2학년 수준의 수학 RPG 게임입니다. 시작 화면 문구처럼 "으뜸이&에이미와 함께 악당을 무찔러보자!"라는 콘셉트로, 딱딱한 계산 문제 풀이를 캐릭터 배틀 형식으로 풀어냈습니다.

2. 주요 기능

  • 용사 이름 입력 : 시작 화면에서 플레이어(학생) 이름을 입력해 자신만의 용사로 게임에 참여합니다.
  • 스테이지(악당) 선택 : 드롭다운에서 도전할 악당 스테이지를 고를 수 있습니다. 예) "Lv 1. 야식유혹 야식마왕" – "밤마다 라면과 떡볶이 사진으로 집중을 방해하는 악당"처럼 각 악당마다 재미있는 설정과 소개 문구가 붙어 있습니다.
  • 뺄셈 문제 배틀 : "대결 시작!" 버튼을 누르면 배틀이 시작되며, 초등 2학년 수준의 뺄셈 문제를 풀어 정답을 맞히는 방식으로 악당에게 맞서 싸웁니다.
  • 화면 우측 상단 스피커 아이콘으로 배경음 · 효과음을 켜고 끌 수 있습니다.

3. 사용 방법

  1. 배포된 웹앱 링크에 접속하면 시작 화면이 나타납니다.
  2. "용사 이름 입력" 칸에 이름을 입력합니다.
  3. "스테이지 악당 선택" 드롭다운에서 도전할 악당을 고릅니다. (기본값은 Lv 1. 야식유혹 야식마왕)
  4. "대결 시작!" 버튼을 눌러 배틀을 시작합니다.
  5. 화면에 나오는 뺄셈 문제를 풀어 정답을 입력(또는 선택)합니다. 정답을 맞히면 악당을 공격하고, 오답이면 불리해지는 방식으로 진행됩니다.
  6. 악당을 모두 물리치면 승리하며, 다시 도전하거나 다른 스테이지를 선택해 이어서 플레이할 수 있습니다.

4. 코드 구조

Google Apps Script 웹앱(doGet으로 서비스되는 HTML 페이지)으로 구성되어 있으며, 시작 화면에서 입력한 용사 이름과 선택한 스테이지 정보를 바탕으로 배틀 화면을 렌더링하는 구조입니다. 문제 출제 · 채점 · 캐릭터 애니메이션 · 사운드 재생은 모두 클라이언트 측 JavaScript로 처리됩니다.

5. 주의사항

  • 초등 2학년 수준의 뺄셈 문제로 구성되어 있으므로, 다른 학년 · 난이도 학생에게는 난이도가 맞지 않을 수 있습니다.
  • 용사 이름을 입력하지 않고 "대결 시작!"을 누르면 진행이 되지 않거나 안내 문구가 나타날 수 있으니, 이름을 먼저 입력하도록 안내합니다.
  • 반드시 "액세스 권한: 모든 사용자"로 배포된 웹앱 링크로 접속해야 정상 작동합니다.
  • 진행 상황 · 점수가 별도로 저장되지 않으므로, 다시 접속하면 처음 화면부터 다시 시작됩니다.
