정기시험 결과분석 교과협의록 자동화

사용 매뉴얼

1. 개요

정기시험 후 작성해야 하는 "결과분석 및 활용방안 교과협의록"을 구글 스프레드시트에 자료를 입력·업로드하는 것만으로 정해진 한글(HWPX) 양식에 자동으로 채워 넣어주는 프로그램입니다. 기본자료 탭에서 최대 3개 과목을 동시에 작업할 수 있고, 교사별로 "개인 작업 사본"을 따로 만들어 여러 사람이 동시에 사용해도 자료가 섞이지 않도록 되어 있습니다.

2. 주요 기능

  • 기본자료 탭에 3개 과목 블록이 나란히 배치되어 최대 3과목을 한 번에 작업
  • 과목별 학년·학기·차수·예상평균 입력, 추정분할/고정분할 방식 선택
  • 단계별 체크박스를 누르면 팝업창이 열려 자료를 입력·업로드: 0. 이원목적분류표(나이스 엑셀) 업로드, 1. 평가 결과 개요(응시자·최고점·최하점·평균) 입력, 2. 성취수준별 분포 분석(급간별 인원 입력, 분할점수 자동 계산), 3. 문항 분석-난이도별 정답률(나이스 문항분석표 엑셀 업로드, 예상 난이도와 실제 정답률 편차 자동 산출), 4. 분석 및 발전 방향(입력 자료를 바탕으로 문장 초안 자동 생성, 직접 수정 가능)
  • HWPX 양식 파일을 한 번 업로드해두면 이후 재사용
  • "완료 & 다운로드" 체크박스로 최대 3과목 자료를 하나의 HWPX 교과협의록 파일로 자동 생성, 구글 드라이브에 저장 후 다운로드 링크 제공
  • "데이터 삭제" 체크박스로 과목별 입력 자료를 초기화
  • "개인 작업 사본 만들기"로 사용자 이름이 들어간 복사본을 만들어 원본 파일 보호

3. 사용 방법

  1. 원본 스프레드시트에서 메뉴 "설정&사본만들기" → "최초 설정 / 권한 승인"을 실행합니다. (최초 1회, 권한 승인 포함)
  2. "개인 작업 사본 만들기"를 눌러 본인 이름이 들어간 사본을 열고, 이후 작업은 이 사본에서 진행합니다. (원본에는 입력하지 않음)
  3. 기본자료 탭 상단 체크박스로 HWPX 양식 파일을 업로드합니다. (최초 1회)
  4. 각 과목 블록에 과목명·학년·학기·차수·예상평균을 입력하고, 추정분할 또는 고정분할 중 하나를 선택합니다.
  5. 0~4번 체크박스를 순서대로 눌러 이원목적분류표, 평가 결과 개요, 성취수준별 분포, 문항 분석, 분석 및 발전 방향 자료를 차례로 입력합니다.
  6. 모든 과목 입력이 끝나면 "완료 & 다운로드" 체크박스를 눌러 HWPX 파일을 생성하고, 안내되는 링크로 다운로드합니다.
  7. 내용을 다시 입력해야 하면 해당 과목의 "데이터 삭제" 체크박스로 초기화한 뒤 다시 진행합니다.

4. 코드 구조

Google Apps Script 프로젝트로 구성되며, code.gs 한 파일이 서버 로직 전체를 담당합니다. 기본자료 시트의 화면 구성과 체크박스 클릭 처리(setupBasicSheet_, handleEdit), 나이스 엑셀 파일 해석(convertExcelToValues_ - Drive API 변환 없이 xlsx 내부 XML을 직접 읽어 처리), 단계별 입력 자료 저장, HWPX 템플릿 압축 해제 후 내부 section XML의 표 셀을 문자열 치환 방식으로 채우고 다시 압축해 새 파일로 저장하는 로직(createHwpxFile_, applyHwpxReplacements_ 등)으로 이루어져 있습니다. 파일 업로드, 평가 결과 개요, 성취수준별 분포, 분석 및 발전 방향 입력 등 각 단계의 팝업 화면은 별도의 다이얼로그 HTML로 구현되어 있습니다.

5. 주의사항

  • HWPX 양식 파일을 먼저 업로드해야 "완료 & 다운로드"로 최종 문서를 만들 수 있습니다.
  • 여러 교사가 원본 시트에서 동시에 입력하면 자료가 섞일 수 있으므로, 반드시 "개인 작업 사본"을 만들어 각자 작업해야 합니다.
  • 1학년은 고정분할을 사용할 수 없고 추정분할만 선택할 수 있습니다.
  • 다운로드 전 0~4단계 자료가 모두 입력되어 있어야 하며, 한 HWPX 파일에 함께 넣을 과목들은 차수와 학기가 모두 같아야 합니다.
  • 업로드 파일은 .xlsx 또는 .csv만 지원하며, .xls 파일은 엑셀에서 .xlsx로 다시 저장한 뒤 업로드해야 합니다.
  • 문항 번호는 300번 이하, 정답 선택지는 1~5번까지만 인식됩니다.
