행운의 뽑기

사용 매뉴얼

1. 개요

교직원 행사·동아리 행사 등에서 쓰는 온라인 추첨(뽑기) 웹앱입니다. 담당자가 딱지(번호)판을 준비해 두면 참여자가 번호를 하나 골라 스크래치 카드를 긁듯 당첨 여부를 확인합니다. 참여자를 모으는 방식이 서로 다른 세 가지 행사 유형(이미 명단이 있는 경우, 사전 등록을 받는 경우, 현장에서 즉석으로 진행하는 경우)을 모두 지원하며, Code.gs와 index.html 두 파일만으로 구성되어 있어 사본을 뜨는 것만으로 바로 새 행사를 시작할 수 있습니다.

2. 주요 기능

  • 참여방식 3가지 : "명단"(담당자가 참여자 명단을 미리 준비), "등록"(참여자가 행사 전 이름·확인번호를 직접 등록하고 담당자가 마감), "자유"(이름만 적고 현장에서 바로 뽑기)
  • 뽑기판 · 스크래치 연출 : 번호가 매겨진 딱지 중 하나를 고르면 스크래치 카드가 나타나고, 화면을 문질러 지우면 당첨/꽝 결과가 드러남
  • 경품 관리 : 경품명·인원수·당첨문구를 관리자 화면에서 여러 개 등록, 모두 비우면 "당첨/꽝"으로만 단순 진행
  • 당첨번호 자동 생성 : 전체 딱지 수 중에서 경품별 인원수만큼 무작위로 당첨번호를 배정
  • 관리자 화면 한 곳에서 운영 : 행사명·안내문구·확인번호라벨·딱지수 등 설정, 참여자 명단 붙여넣기(엑셀 복사 지원), 경품 편집, 당첨번호 생성, 실시간 참여 현황표, 관리자 비밀번호 변경까지 시트를 직접 열지 않고 처리
  • 뽑기판 현황(미리보기) : 관리자만 볼 수 있는 화면으로, 딱지마다 누가 뽑았는지와 당첨/꽝 결과를 색과 글자로 함께 표시 (색각 이상·흑백 인쇄 대비)
  • 등록 마감 자동 처리 : "등록" 방식에서 마감 버튼 하나로 딱지 수 확정 → 당첨번호 생성 → 진행상태 전환까지 한 번에 처리
  • 안내 탭 동봉 : 초기 설정을 실행하면 스프레드시트 맨 앞에 "안내" 탭이 만들어져 행사 준비부터 종료까지의 운영 안내가 함께 딸려감 (별도 매뉴얼 문서를 전달하지 않아도 됨)
  • 재사용 · 초기화 : 같은 명단으로 다시 진행(기록만 초기화)하거나, 완전히 새 행사로 시작(기록+명단 모두 초기화) 가능

3. 사용 방법

  1. 스프레드시트 사본을 뜬 뒤, 메뉴 🎟️ 행운의 뽑기 → ① 초기 설정을 실행해 필요한 시트(설정·명단·경품·당첨번호·기록·안내)를 만듭니다.
  2. 확장 프로그램 → Apps Script → 배포 → 새 배포 → 웹 앱으로 배포합니다. (실행: 나 / 액세스: 조직 내 모든 사용자 등 행사 대상에 맞게 설정)
  3. 배포된 링크를 열고 화면 맨 아래 "관리자"를 눌러 로그인합니다. 기본 비밀번호는 1234이며, 로그인 직후 반드시 비밀번호를 변경합니다.
  4. [⚙️ 설정]에서 참여방식(명단/등록/자유)과 행사명, 안내문구, 확인번호라벨(내선번호·학번 등) 등을 정합니다.
  5. 방식에 따라 참여자를 준비합니다: 명단 방식은 [👥 참여자 명단]에 이름과 확인번호를 붙여넣고, 등록 방식은 진행상태를 "등록중"으로 두고 링크를 안내한 뒤 다 모이면 [등록 마감]을 누르며, 자유 방식은 [딱지수]를 직접 입력합니다.
  6. [🎁 경품]에 경품명·인원수·당첨문구를 등록합니다. (모두 비우면 [당첨인원수]만큼 당첨/꽝으로만 진행)
  7. [🎲 당첨번호] → [당첨번호 생성]을 눌러 당첨번호를 만듭니다. (등록 방식은 등록 마감 시 자동 생성되므로 생략 가능)
  8. 진행상태를 "진행중"으로 바꾸고 참여자에게 링크를 안내하면, 참여자는 이름(및 확인번호)을 입력한 뒤 딱지를 골라 스크래치로 결과를 확인합니다.
  9. 행사 중에는 관리자 화면의 [📋 참여 현황]과 [뽑기판 현황 보기]로 실시간 진행 상황을 확인합니다.
  10. 행사가 끝나면 설정의 진행상태를 "종료"로 바꾸고, 같은 명단으로 다시 진행할 경우 [기록 초기화], 새 행사를 시작할 경우 [기록+명단 모두 비우기]를 사용합니다.

4. 코드 구조

Google Apps Script 프로젝트로, Code.gs(서버 로직)와 화면 전체를 담은 index.html 한 파일로만 구성되어 외부 CDN 없이 학교망에서도 그대로 동작합니다. 스프레드시트는 "안내"(운영 매뉴얼, 초기 설정 시 자동 작성), "설정"(행사명·참여방식·진행상태 등 항목-값), "명단"(참여자 이름·확인번호·뽑기 결과), "경품"(경품명·인원수·당첨문구), "당첨번호"(당첨 딱지 번호-경품명), "기록"(참여자별 뽑기 로그) 시트로 이루어져 있습니다. 서버 함수는 참여자용 API(getInitData, registerParticipant, checkParticipant, drawTicket 등)와 관리자용 API(getAdminData, savePrizes, saveMembers, generateWinningNumbers, adminCloseRegistration, adminResetRound 등)로 나뉘며, 동시에 여러 명이 같은 번호를 누르는 상황은 LockService로 막습니다.

5. 주의사항

  • 기본 관리자 비밀번호(1234)를 그대로 두면 링크를 아는 누구나 관리자 화면에 들어올 수 있으므로 반드시 변경해야 합니다.
  • 당첨번호를 생성하지 않은 채로 뽑기를 시작하면 모두 꽝으로 처리됩니다. (가장 흔한 실수)
  • 자유 방식에서 [딱지수]를 0으로 두면 뽑기판 자체가 만들어지지 않습니다.
  • 등록 방식은 진행상태가 "등록중"인 동안에는 뽑기를 시작할 수 없고, [등록 마감]을 눌러야 딱지 수가 확정되고 뽑기가 시작됩니다.
  • 이미 뽑기 기록이 있는 상태에서 명단을 통째로 교체(replace)하거나 경품을 바꾸면 기존 당첨번호와 어긋날 수 있어, 아무도 뽑지 않았을 때만 당첨번호가 자동으로 다시 생성됩니다.
  • 관리자 화면(특히 뽑기판 현황 보기)에는 당첨번호가 그대로 노출되므로 참여자와 함께 보면 안 됩니다.
  • 확인번호는 비밀번호가 아니라 동명이인을 구분하기 위한 값이며, 참여자에게 보여줄 명칭(학번/내선번호 등)은 [확인번호라벨]에서 바꿀 수 있습니다.
