어휘 포격대(9살 국어 어휘)

사용 매뉴얼

1. 개요

기존 어휘 포격대와 같은 "성벽 포격" 게임 엔진을 그대로 사용하되, 문제 데이터만 만 9세(초등 저학년) 학생 눈높이에 맞춘 국어 어휘로 교체한 버전입니다. 문장 속 빈칸 [ ? ]에 들어갈 낱말을 4개의 보기 중에서 골라 성벽을 포격하는 방식은 동일하며, 별도의 구글 시트에 연결되어 있어 원래 어휘 포격대와는 독립적으로 문제를 관리합니다.

2. 주요 기능

  • 기본 게임 방식(무작위 10문항 출제, 포격 · 성벽 파손 연출, 오답 시 시간 절반 페널티, 점수 · 구간 보너스, 명예의 전당 랭킹 등)은 어휘 포격대와 동일합니다.
  • 문제는 "우리 동네에는 주민들의 안전을 [ ? ]하는 경찰서와 소방서가 있습니다."처럼 생활 속 문장에서 알맞은 낱말을 고르는 형식으로, 저학년 학생도 이해하기 쉬운 문장과 어휘로 구성되어 있습니다.
  • 연결된 구글 시트만 별도로 관리하므로, 기존 어휘 포격대의 문제·랭킹과 섞이지 않고 독립적으로 운영됩니다.

3. 사용 방법

  1. 게임이 로딩되면(구글 연동 대기) 화면을 한 번 클릭해 배경음악을 재생합니다.
  2. 화면에 표시된 문장의 빈칸 [ ? ]에 들어갈 알맞은 낱말을 하단 4개의 보기 버튼 중에서 고릅니다.
  3. 정답을 고르면 대포가 발사되어 성벽에 명중하고, 남은 시간에 따라 점수를 얻습니다.
  4. 오답을 고르면 해당 보기가 불발 처리되고 남은 시간이 절반으로 줄어들며, 잠시 후 남은 보기로 다시 시도할 수 있습니다.
  5. 제한 시간이 다 되거나 정답을 맞히면 해설 팝업이 뜨고, "NEXT ATTACK MOVE" 버튼으로 다음 문제로 넘어갑니다.
  6. 10문항을 모두 마치면 최종 파손율과 점수가 표시되며, 이니셜을 입력해 명예의 전당에 점수를 올릴 수 있습니다.

4. 코드 구조

어휘 포격대와 동일한 Google Apps Script 프로젝트(code.gs + index.html)를 복사해, 연결 대상 구글 시트만 9세 국어 어휘 문제용 시트로 교체한 버전입니다. 문제(문장 · 보기 4개 · 정답 번호 · 해설)를 읽어 무작위로 섞어 10문항을 출제하는 로직과 Ranking 시트를 이용한 점수 기록 로직은 원본과 같습니다.

5. 주의사항

  • 문제 데이터는 이 버전 전용 구글 시트에서 관리하며, 원본 어휘 포격대의 시트와는 별개이므로 문제를 추가·수정할 때 시트를 혼동하지 않도록 주의합니다.
  • 데이터 형식(문장 · 보기 4개 · 정답 번호 · 해설)은 원본 어휘 포격대와 동일하게 맞춰야 정상 출제됩니다.
  • 반드시 "액세스 권한: 모든 사용자"로 배포된 웹앱 링크로 접속해야 정상 작동합니다.
  • 오답 시 남은 시간이 절반으로 줄어드는 페널티가 있으므로, 저학년 학생에게는 문제를 천천히 소리 내어 읽어보도록 안내하면 좋습니다.
