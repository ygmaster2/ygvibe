수업ON

사용 매뉴얼

1. 개요

수업 시간표 · 단원별 진도 · 출결 · 수업일지 · 수업 참여 기록(자리 배치 · 토큰 · 행운의 뽑기)까지 수업 운영에 필요한 것을 한 화면에서 관리하는 구글 스프레드시트 + Apps Script 웹앱입니다. 배포된 링크로 스프레드시트 사본을 만들고 웹앱으로 배포하기만 하면, 별도 설치 없이 선생님 각자의 독립된 사본으로 바로 사용할 수 있습니다.

2. 주요 기능

  • 설정 : 학기(학년도 · 학기 · 시작일 · 종료일), 교시 시간, 담당 반(과목명 · 반이름 · 강의실 · 대표색상)을 등록합니다. 여러 학기를 등록해 두고 오른쪽 위에서 오갈 수 있습니다.
  • 주간 시간표 : 빈 칸을 클릭해 반만 고르면 요일 · 교시 · 시각이 자동으로 채워집니다.
  • 단원별 진도표 : 단원을 등록하고 [예정일 자동 배치]로 진도 일정을 짤 수 있으며, 교과서 목차가 있으면 [일괄 등록]으로 한 번에 붙여넣을 수 있습니다.
  • 출결 · 수업일지 : 학생 명단(학번,이름 형식 또는 나이스 출석부 표 붙여넣기)을 기준으로 출결과 수업일지를 기록합니다.
  • 대시보드 : 오늘 수업, 진도 현황 등을 한눈에 확인할 수 있는 첫 화면입니다.
  • 수업 참여 기록 : 자리 배치와 토큰(참여 점수) 부여, 토큰을 활용한 행운의 뽑기, 누적 통계 보기까지 지원합니다.
  • 자료 백업 : 필요할 때 직접 백업을 실행할 수 있습니다.
  • 사용설명서 내장 : 프로그램 안 [대시보드] 화면 오른쪽 위 [사용설명서]를 누르면 화면별 자세한 사용법이 새 창으로 열리며, 인쇄 · PDF 저장도 가능합니다.

3. 사용 방법

가) 사본 만들기 · 배포 (처음 한 번만)

  1. 배포된 링크(구글 스프레드시트 /copy 링크)를 열면 "사본을 만드시겠습니까?"라는 안내가 뜹니다. 사본 만들기를 눌러 내 계정에 스프레드시트 사본을 만듭니다. (스크립트까지 함께 복사됩니다)
  2. 사본에서 확장 프로그램 → Apps Script → 배포 → 새 배포를 선택하고, 유형을 웹 앱으로 지정해 배포합니다. (실행 계정: 나, 액세스 권한: 나만)
  3. 권한 검토 화면이 뜨면 계정을 선택하고 고급 → (안전하지 않은 페이지)로 이동 → 허용 순서로 권한을 승인합니다.
  4. 배포가 끝나면 발급된 웹앱 주소를 즐겨찾기에 저장합니다. 앞으로는 이 주소로만 접속합니다.
  5. 처음 접속하면 시트 20장이 자동으로 만들어지며(약 20초 소요), 다음부터는 바로 열립니다.

나) 실제 사용

  1. [설정] 탭에서 학기, 교시 시간, 담당 반을 먼저 등록합니다. (뒤에서 쓰는 값들이 앞선 설정을 참조하므로, 이 순서를 지키는 것이 중요합니다)
  2. [주간 시간표] 탭에서 빈 칸을 클릭해 반을 배정합니다.
  3. [설정] 탭에서 반별 학생 명단을 붙여넣습니다.
  4. [단원별 진도표] 탭에서 단원을 등록하고 예정일을 배치합니다.
  5. 이후 [출결 · 수업일지], [대시보드], [수업 참여 기록] 화면에서 일상적으로 수업을 운영 · 기록합니다.
  6. 더 자세한 화면별 사용법은 프로그램 안 [대시보드] 오른쪽 위 [사용설명서]를 참고합니다.

4. 코드 구조

Google Apps Script 프로젝트로, Code.gs(서버 로직)와 Index.html · JavaScript.html · Style.html 세 개의 HTML 파일로 구성되어 있습니다. 스프레드시트가 데이터베이스 역할을 하며, 첫 접속 시 학기 · 시간표 · 진도 · 출결 · 수업일지 · 참여기록 등에 필요한 시트가 자동으로 만들어집니다. 배포된 사본마다 스프레드시트와 웹앱이 독립적으로 동작하므로, 사용자(선생님) 간에 데이터가 섞이지 않습니다.

5. 주의사항

  • 반드시 안내된 /copy 링크로 사본을 새로 만들어 사용해야 합니다. 이미 사용 중인 원본을 복사해 배포하면 안 됩니다.
  • 웹앱 배포와 권한 승인은 사본을 만드는 것만으로 자동으로 되지 않으며, 사용자가 자신의 계정에서 직접 진행해야 하는 유일한 작업입니다.
  • 설정(학기 · 교시 시간 · 담당 반)을 먼저 채우지 않으면 시간표 · 진도표 등 다른 화면이 정상적으로 표시되지 않을 수 있습니다.
  • 처음 접속 시 시트 20장이 자동 생성되는 데 약 20초가 걸리며, 이 동안 화면이 멈춘 것처럼 보일 수 있으니 기다려야 합니다.
  • 배포 후 발급되는 웹앱 주소는 사본마다 다르므로, 각자 자신의 주소를 저장해 두어야 합니다.
